# 信标提醒台

设定一个时刻，写下要对自己说的话。时间到了，浏览器发系统通知并全屏响铃。单个 HTML
文件，无构建、无外部请求，和上一级的[课程排程台](../)共用同一套设计系统——松石绿为
骨、杏橙为触发状态、卡片+侧栏的桌面优先布局，浅色为主、深色随系统自动切换。

在线使用：https://echo844883.github.io/Claude-/beacon/

## 界面

顶部一条统计栏：已武装数量、下一次触发、通知权限状态。左侧栏是「授权」（通知、声音、
屏幕常亮，逐项请求）和「说明」；右侧主区是「待命队列」，每条提醒左边一条色带（六色
轮转），时刻、消息、重复方式与实时倒计时，右边可启停、删除。「新建提醒」和到点的
响铃都是原生对话框：时刻、提醒内容、重复方式（仅一次 / 每天 / 按星期）。

## 三种权限，都在本机

- **系统通知** — 允许后到点推到锁屏。必须由你点击按钮触发，浏览器不接受自动请求。
- **声音与振动** — 手机浏览器要求先有一次用户点击才允许发声，做成「试听」按钮。
- **屏幕常亮** — Screen Wake Lock API，有待命提醒时阻止息屏。可选，部分浏览器不支持。

## 已知限制（请务必知道）

网页闹钟靠这个页面自己计时：

- **页面被完全关掉（不是断网）就不会响。** 留在前台或后台标签页 / 已安装的 App 里。
- **iPhone** 需要先「添加到主屏幕」，从主屏图标打开才能收到系统通知（iOS 16.4+）。
- **嵌在 iframe 里时无法申请通知权限**，浏览器只允许顶层窗口申请，页面会提示你在
  独立标签页打开。
- 系统长时间挂起标签页会延迟触发；回到前台会立刻补发，并标注「错过的信标」。
- 重要的事情，请同时设一个系统自带闹钟。

## 离线使用

下载单个 `index.html` 双击打开，从第一秒起就不需要联网——数据存本机、图片全内嵌、
零外部请求。通过网址访问时，目录里还有 `manifest.webmanifest`、`sw.js` 和四个
`icon-*.png`，让浏览器可以「安装到主屏幕」：装一次、或哪怕只是完整打开过一次之后，
断网重开这个网址也能计时、写提醒、响铃。这个 Service Worker 的作用域只到
`/beacon/`，和上一级课程排程台自己的 Service Worker 互不影响。

改了 `index.html` 之后要更新已安装用户的缓存，把 `sw.js` 里的 `VERSION` 常量加一。

## 数据存哪

只存在你自己浏览器的 localStorage 里（键名 `beacon.reminders.v1`），不上传任何
服务器，本仓库也不会收到你的任何数据。换设备或清缓存前，请自行截图或记下重要提醒。

## 自检

打开 `index.html?test=1`，控制台跑 12 项断言：重复规则的时刻推算、倒计时文案、
侧栏卡片数量、新建/响铃均为原生 dialog、文档不横向溢出。
